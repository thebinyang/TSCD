# TSCD
Temporal Information Enhanced Graph Convolutional Network with Superpixel-Pixel Gated Knowledge Dynamic Selection for Change Detection in Satellite Time Series

This repository includes codes and dataset for "Temporal Information Enhanced Graph Convolutional Network with Superpixel-Pixel Gated Knowledge Dynamic Selection for Change Detection in Satellite Time Series", which has been published in IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing.

The materials in this repository are only for study and research, **NOT FOR COMMERCIAL USE**.  

If this code is helpful for you, please consider citing:  
B. Yang, X. Cheng, J. Guo and X. Ye, "Temporal Information Enhanced Graph Convolutional Network With Superpixel-Pixel Gated Knowledge Dynamic Selection for Change Detection in Satellite Time Series," in IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing, vol. 17, pp. 18399-18412, 2024, doi: 10.1109/JSTARS.2024.3468949.
